Engine

The AI that makes the base photos, for every batch and the Agent. Its key goes in API keys below.

Your own GPU pod running the open Qwen-Image-Edit model (pilot/runpod/README.md). You pay RunPod per hour, so stop the pod when the batch is done. Set parallel requests to 1: the pod's web address gives up on a request after about 100 s, and extra requests only queue on the one GPU.

API keys

Saved keys are used by every batch. They stay on this computer or server and are never shown again.

One-time setup (about 5 minutes): Google needs an "OAuth client" from your own Google account.

  1. Open Google Auth Platform (sign in, pick or create a project), press Get started: app name Jag Studio, your email, External, Create.
  2. In Audience, press Publish app (so the connection doesn't expire after 7 days).
  3. Open Google Drive API and press Enable.
  4. In Clients, Create client: type Web application, and under Authorized redirect URIs add:
  5. Press Create, then paste the Client ID and Client secret here:

Print folders

Where your prints (PNG artwork) are in Google Drive, for each category, top style and colour. Add prints above puts every print from the matching folder on a batch's finished front photos: exactly as drawn, following the shirt's folds and light, no AI and no cost. A folder set for All colours is used for any colour that has no folder of its own.

Google Drive is connected without permission to read your folders. An admin presses Connect Google Drive once more and allows it.
